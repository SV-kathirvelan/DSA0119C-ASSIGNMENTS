# Metro Smart-Card System – Assignment 1 (C++)

This repository contains beginner-friendly C++ demonstrations for all 12 tasks in the supplied assignment PDF. Each task folder contains a `.cpp` source file and a sample output text file.

## Compile and run
Use a C++17 compiler (such as g++). From a task folder run:

```bash
g++ -std=c++17 -Wall -Wextra -pedantic Task1.cpp -o Task1
./Task1
```

On Windows, run `Task1.exe` after compiling. Change the filenames for the relevant task.

## Task list
1. Identify system objects – simple SmartCard class
2. Tokens, keywords, identifiers and constants
3. Data types and type compatibility
4. Implicit conversions and explicit casts
5. Operator precedence and expressions
6. Control structures and fare calculation
7. Procedural programming versus OOP
8. Safe input and output validation
9. Fare logic test cases
10. Integer range and network-scale totals
11. Recommended OOP fare design
12. Revised design with Airport zone, weekend discount and monthly pass

## Important submission note
The output files are sample outputs produced by compiling and running these programs. Compile and run them on your own computer, capture your own terminal screenshots, and commit your work progressively as required by your instructor. Task 8's output file shows a sample valid input (`8`) and invalid input (`abc`).
