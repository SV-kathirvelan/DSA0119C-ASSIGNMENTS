This program checks correctness and measures runtime on your own computer.
It runs 1,000, 1,000,000 and 10,000,000 bill records, then compares status checks
with exceptions for 0%, 1% and 50% invalid claims.

Timing values depend on your CPU, compiler, operating system and load.
Do not copy another person's timings into your submission. Run the program and
record your own output. For more reliable results, run it several times and
report the median.
